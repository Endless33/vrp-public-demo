Frequently Asked Questions

Is this the full VRP runtime?

No.

This repository contains the public demonstration project only.

The protected VRP runtime implementation is not included.

---

What is the purpose of this project?

The purpose of the demo is to allow engineers and organizations to observe publicly verifiable VRP behavior.

The focus is on observable runtime properties rather than implementation details.

---

Can I evaluate VRP without access to the protected runtime?

Yes.

The public demonstration is specifically designed for independent evaluation of publicly observable protocol behavior.

---

What does the demo verify?

Depending on the selected scenario, the demonstration may verify:

- Session establishment
- Session continuity
- Transport migration
- Replay rejection
- Stale-state rejection
- Authority validation
- Deterministic runtime behavior

---

Does this repository contain proprietary algorithms?

No.

Protected implementation details are intentionally excluded.

---

Is the architecture public?

Yes.

The public architecture is documented in the VRP Specification.

The implementation remains protected.

---

Can I use this repository in my own evaluation?

Yes.

The public demonstration is intended to support engineering evaluation, education, and architectural understanding.
